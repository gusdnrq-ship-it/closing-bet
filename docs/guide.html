종가배팅 사용법

내일 종가가 오를까 내릴까 — 방향을 예측해 적중률을 쌓는 시그널 대시보드 (3분 이해)

규칙 1T일 종가로 시그널 발생 규칙 2다음 거래일 종가로 적중/미달 판정 규칙 3스코어보드는 적중률 + 표본수만

1. 어떤 원리인가요?

왜 "장 마감 후"에 실행하나요?
시그널도 판정도 전부 종가 기준입니다. 장이 끝나고(15:30) 네이버 증권에 종가가 반영된 후에 실행해야 오늘 데이터가 잡힙니다. 오후 늦은 저녁에 하루 1번 돌리면 되고, 다음 거래일 판정은 그 다음 날 실행할 때 자동으로 계산됩니다.

2. 딱 3가지 명령

1처음 딱 1회 — 준비 (프로젝트 폴더에서)

python run.py universe     # 코스피·코스닥 전체 종목 목록 받기 (~2,700종목)
python run.py backfill     # 5년치 가격 데이터 받기 (~10분, 1회면 끝)

2매일 1회 — 스캔 (장 마감 후)

python run.py refresh      # 오늘자 종가 추가 (증분)
python run.py scan         # 오늘 시그널 생성 + 어제 시그널 판정
관리종목·거래정지는 자동 제외됩니다. 거래소가 관리종목으로 지정한 종목은 매수 배지가 뜨지 않고 [제외]로 표시됩니다 (지정일 포함). 지정 상태는 universe로 매일 갱신됩니다.

3보기 — 대시보드 켜기

python run.py serve        # 브라우저에서 http://127.0.0.1:8788 접속
명령을 안 쳐도 됩니다. 대시보드 오른쪽 위 [스캔 실행] 버튼을 누르면 scan(판정 + 시그널 생성)이 바로 실행됩니다. 다만 오늘 종가를 받으려면 먼저 refresh가 필요하므로, 완전히 자동이 아니라면 위 2줄을 지키는 게 가장 안전합니다.

3. 대시보드 화면 읽는 법

4. 스코어보드를 올바르게 읽는 법

표시의미
적중률 %시그널이 실제와 같은 방향으로 끝난 비율 (방향만, 손익 금액은 없습니다)
표본수판정된 건수. 10건 미만이면 통계적 의미가 없으므로 숫자만 보고 결론 금지
대기(PENDING)아직 다음 거래일 종가가 나오지 않아 판정 전
무효(VOID)상장폐지·거래정지 등으로 판정할 수 없음 (30일 내 미판정 시)
⚠ 경고문전략별 caveats — 예: "돌파 당일 많이 오른 종목은 익일 되돌림이 잦다"

5. 자주 묻는 질문

  • 몇 시에 실행해야 하나요? — 장 마감(15:30) 후 네이버 반영이 끝난 저녁에 하루 1번. 이틀에 한 번만 써도 판정은 정상 누적됩니다.
  • 판정은 언제 되나요? — 시그널 다음 거래일 종가가 반영된 후 scan을 돌리면 자동으로 적중/미달이 붙습니다.
  • 매매 추천인가요? — 아닙니다. 참고용 정보이며 실제 매매 판단과 책임은 본인에게 있습니다.
  • 시그널이 매일 없나요? — 신호가 없을 수 있습니다(쌍굴파기 전략은 매우 드물게 발생). 없는 날이 정상입니다.
  • 데이터는 어디서? — 네이버 증권 read-only API. 유니버스 1회 + 가격 데이터 갱신은 인터넷만 있으면 됩니다.
유의사항 — 적중률은 항상 표본수와 함께 확인하세요. 표본 10건 미만은 우연일 수 있습니다. 전략은 과거 데이터로 검증했으나 미래 수익을 보장하지 않습니다.
