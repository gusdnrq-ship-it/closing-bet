## 0. 하루 흐름 (장 마감 ~ 다음 장 시작)

| 시각(KST) | 할 일 |
|---|---|
| 15:40~ | 알림 수신 → 대시보드 `1. 오늘`에서 **매수** 배지 종목 확인 |
| ~21:00 | 자문·주문 시트 확인, 다음날 체결 가격(지정가)만 정해두고 끝 |
| 다음 거래일 09:00 | 시장가 또는 지정가(시가 ±1%) 1회 체결. **10시 이후 신규 진입 금지** |
| 장 중 | 손절가·목표가 조건 감시. **新加 매수·물타기 없음** |
| 장 마감 후 | 매매일지 기록, 스캔/판정 결과 확인 |

## 1. 진입 (Entry)

1. **어떤 종목을**: 자문(advice)의 `매수(BUY)` 배지만. `관망`은 관찰, `제외`는 건드리지 않는다.
2. **언제**: 신호가 나온 **다음 거래일 장 시작**. 09:00 시가 체결이 기본.
3. **주문**: 지정가는 `시가 ±1%` 범위. 10시까지 미체결이면 **체결 포기** (재진입 금지).
4. **건수**: 포지션 사이저(`3. 상세히 보기 → 매매 도구`)가 제시한 수량 그대로.
5. **동시 신규 매수**: 최대 3종목. 총 신규 매수금은 자본의 **60%** 이내 (현금 40% 유지).

## 2. 사이징 (Position Sizing)

- **1회 리스크 = 자본의 1%** (예: 300만 원이면 3만 원)
- 수량 = `1회 리스크 한도 ÷ (진입가 − 손절가)` 와 `자본 × 20% ÷ 진입가` 중 **작은 값**
- 절대 규칙: 손절가까지 가도 손실이 자본의 1%를 넘는 수량은 매수하지 않는다.

## 3. 매도 (Exit) — 조건 3개 중 하나라도 충족하면 즉시 매도

| 조건 | 값 | 근거 |
|---|---|---|
| **손절 (SL)** | 신호 이전 **60거래일 최저가** 하회 | 자금 보호선. 백테스트에서 이점 입증 안 됨(손절 실패 결론) → **그래도 지킨다**. 지키지 않으면 한 번의 -30%가 자본을 잡아먹는다 |
| **목표 (TP)** | **60일 이동평균** 도달 | BNF에서만 유효(+27~30% > 보유 +21~23%). breakout은 진입 당일 발동되어 사실상 T+1 매도 |
| **시간** | 진입 후 **20거래일** 경과 | 규칙이 먼저 발동하지 않으면 그냥 매도 (검증에서 규칙 전체보다 대개 우위) |

- **물타기 금지**, **손절 후 같은 종목 재진입 금지**, **평균가 정정 금지**.
- 익일 종가 판정(대시보드 성적)은 **매매와 별개** — 매매일지가 실질 손익이다.

## 4. 리스크 상한 (한도)

| 항목 | 한도 | 비고 |
|---|---|---|
| 종목 1개 투자금 | 자본의 **20%** | 사이즈 상한 |
| 1회 손실 | 자본의 **1%** | 손절 기준 |
| 총 신규 매수 | 자본의 **60%** | 현금 40% 유지 |
| 동시 보유 | **3종목** | 초과 시 신규 진입 금지 |
| 일일 손실 | 자본의 **3%** | 도달하면 당일 매매 중단 |

## 5. 자문 배지의 의미

| 배지 | 조건 | 행동 |
|---|---|---|
| **매수** | 전략 게이트 통과(BNF 검증 57.0%, breakout 3조건 51.3%) + 위험 배지 '양호' + 손절·목표 산출 완료 | 지침대로 진입 |
| **관망** | 게이트 통과했으나 위험 '주의' 1건 이상, 또는 손절·목표 산출 불가 | 관찰만. 다음 신호 대기 |
| **제외** | 위험 '위험'(2건 이상) / 전략 미달(breakout 전체 45.8% < 기준선) / 쌍굴 표본부족 / 내림 방향 | 손대지 않음 |

- **전략 게이트**: 기준선 46.89%를 검증기간 적중률로 넘는 조건에서만 매수 허용.
  breakout 전체(45.8%)는 기준선 하회이므로 **조건 3개**(돌파폭≥10% & 5일대금≥100억 & RSI≥80)가
  모두 충족할 때만 매수 후보가 된다. 쌍굴파기는 검증 n=152로 **표본 부족 → 항상 제외**.

## 6. 절대 금지

1. 손절 미이행 ("한 번 더 본다")
2. 자본의 1%를 넘는 수량 매수
3. 하락 추세 종목에서의 물타기
4. 뉴스·유튜브·팔로워 말로만 한 매매 (자문 배지 없이)
5. 연속 손실 후 사이즈 증액 (리벤지 트레이딩)

## 7. 기록

- 모든 매매는 `매매일지`에 **당일 기록** (진입가·손절가·수량·사유).
- 주문 시트는 `3. 상세히 보기 → 매매 도구`에서 CSV로 내려받아 증권사 주문 화면에 입력.
- 주문 파일 규격은 `docs/orderspec.md`.
