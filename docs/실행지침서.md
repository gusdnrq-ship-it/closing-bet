# 종가배팅 실행 지침서 (소액 실전 · 자본 수백만 원 기준)

> 이 문서는 **실행 규칙**을 숫자로 확정한 문서입니다. 신호의 근거(검증·표본수)는
> 대시보드 `1. 오늘 / 2. 지난 기록 / 3. 상세히 보기`와 `docs/20260929_분석리포트.md`를 보십시오.
>
> **본 지침서와 대시보드의 모든 정보는 참고자료이며 매매 추천이 아닙니다.**
> 투자 판단과 손실 책임은 본인에게 있습니다.

---

## 0. 하루 흐름 (장 마감 ~ 다음 장 시작)

| 시각(KST) | 할 일 |
|---|---|
| 15:40~ | 알림 수신 → 대시보드 `1. 오늘`에서 **매수** 배지 종목 확인 |
| ~21:00 | 자문·주문 시트 확인, 다음날 체결 가격(지정가)만 정해두고 끝 |
| 다음 거래일 09:00 | 시장가 또는 지정가(시가 ±1%) 1회 체결. **10시 이후 신규 진입 금지** |
| 장 중 | 손절가·목표가 조건 감시. **新加 매수·물타기 없음** |
| 장 마감 후 | 매매일지 기록, 스캔/판정 결과 확인 |

---

## 1. 진입 (Entry)

1. **어떤 종목을**: 자문(advice)의 `매수(BUY)` 배지만. `관망`은 관찰, `제외`는 건드리지 않는다.
2. **언제**: 신호가 나온 **다음 거래일 장 시작**. 09:00 시가 체결이 기본.
3. **주문**: 지정가는 `시가 ±1%` 범위. 10시까지 미체결이면 **체결 포기** (재진입 금지).
4. **건수**: 포지션 사이저(`3. 매매 도구`)가 제시한 수량 그대로.
5. **동시 신규 매수**: 최대 3종목. 총 신규 매수금은 자본의 **60%** 이내 (현금 40% 유지).

## 2. 사이징 (Position Sizing)

- **1회 리스크 = 자본의 1%** (예: 300만 원이면 3만 원) — **절대 상한. 어떤 경우에도 넘지 않는다.**
- 수량 = `1회 리스크 한도 ÷ (진입가 − 손절가)` 와 `종목 한도 ÷ 진입가` 중 **작은 값**
- 절대 규칙: 손절가까지 가도 손실이 자본의 1%를 넘는 수량은 매수하지 않는다.

### 2-1. 신뢰도 배율 (게이트 사후 상태 → 사이즈)

같은 1% 리스크라도 **근거가 얼마나 단단한지**에 따라 종목 한도를 조정한다.

| 배율 | 조건 | 종목 한도 | 1회 리스크 |
|---|---|---|---|
| **×1.25** | 95% 구간 하단이 기준선 초과 (사후 확정 통과) | 20% → **25%** | 1% |
| **×1.0** | 백테스트 통과 유지 (사후가 기준선 포함) | 20% | 1% |
| **×0.9** | 조건부 허용 / 표본부족 전략 승격 | 20% → **18%** | 1% → **0.9%** |

- 배율은 **주문 시트에 종목명 옆 `×1.25` / `×0.9` 태그**로 표시된다.
- 원칙: **리스크는 줄이고 늘리지 않는다** — 확정된 근거가 있어도 1회 리스크는 1%를 넘지 않는다.
  커지는 것은 종목 한도(20%→25%)로만 허용한다.

## 3. 매도 (Exit) — 조건 3개 중 하나라도 충족하면 즉시 매도

| 조건 | 값 | 근거 |
|---|---|---|
| **손절 (SL)** | 신호 이전 **60거래일 최저가** 하회 | 자금 보호선. 백테스트에서 이점 입증 안 됨(손절 실패 결론) → **그래도 지킨다**. 지키지 않으면 한 번의 -30%가 자본을 잡아먹는다 |
| **목표 (TP)** | **60일 이동평균** 도달 | BNF에서만 유효(+27~30% > 보유 +21~23%). breakout은 진입 당일 발동되어 사실상 T+1 매도 |
| **시간** | 진입 후 **20거래일** 경과 | 규칙이 먼저 발동하지 않으면 그냥 매도 (검증에서 규칙 전체보다 대개 우위) |

- **물타기 금지**, **손절 후 같은 종목 재진입 금지**, **평균가 정정 금지**.
- 익일 종가 판정(대시보드 성적)은 **매매와 별개** — 매매일지가 실질 손익이다.

## 4. 리스크 상한 (한도)

| 항목 | 한도 | 비고 |
|---|---|---|
| 종목 1개 투자금 | 자본의 **20%** (신뢰도 ×1.25 → 25%, ×0.9 → 18%) | 사이즈 상한 |
| 1회 손실 | 자본의 **1%** (×0.9 근거 → 0.9%) | 손절 기준 · **절대 상한** |
| 총 신규 매수 | 자본의 **60%** | 신뢰도 배율과 무관 (변경 없음) |
| 동시 보유 | **3종목** | 초과 시 신규 진입 금지 |
| 일일 손실 | 자본의 **3%** | 도달하면 당일 매매 중단 |

## 5. 자문 배지의 의미

| 배지 | 조건 | 행동 |
|---|---|---|
| **매수** | 전략 게이트 통과(BNF 검증 57.0%, breakout 3조건 51.3%) + 위험 배지 '양호' + 손절·목표 산출 완료 | 지침대로 진입 |
| **관망** | 게이트 통과했으나 위험 '주의' 1건 이상, 또는 손절·목표 산출 불가 | 관찰만. 다음 신호 대기 |
| **제외** | 위험 '위험'(2건 이상) / 전략 미달(breakout 전체 45.8% < 기준선) / 쌍굴 표본부족 / 내림 방향 | 손대지 않음 |

- **전략 게이트**: 기준선 46.89%를 검증기간 적중률로 넘는 조건에서만 매수 허용.
  breakout 전체(45.8%)는 기준선 하회이므로 **조건 3개**(돌파폭≥10% & 5일대금≥100억 & RSI≥80)가
  모두 충족할 때만 매수 후보가 된다. 쌍굴파기는 검증 n=152로 **표본 부족 → 항상 제외**.
- **게이트는 발전형입니다** — 아래 5-1 참조. 위 고정값은 출발점이고, 실전 판정이 쌓이면
  게이트가 스스로 바뀔 수 있습니다. 매수 전 `3. 매매 도구 → 발전형 게이트`에서
  해당 전략의 **상태(통과/미달/표본부족)**와 `▲ 자동승격/강등` 표시를 확인하십시오.

### 5-1. 발전형 게이트 (자기학습)

매 판정 주기마다 전략별 적중률을 **베이지안**으로 갱신합니다
(`app/learn.py`, 발행물 `static/api/learn.json`).

```
사전분포 = 백테스트 검증승률 (breakout 45.8 / BNF 57.0 / 쌍굴 67.8), 강도 200건
관측     = 실전 판정 (HIT/MISS, VOID·PENDING 제외)
사후분포 = Beta(사전 + 적중, 사전 + 틀림) → 평균과 95% 구간
```

| 사후 95% 구간 vs 기준선 46.89% | 판정 |
|---|---|
| 하단이 기준선 **초과** | 통과 (자동 승격) |
| 상단이 기준선 **미달** | 미달 (자동 강등) |
| 기준선을 **포함** | 판정없음 → **백테스트 판정 유지** |

안전장치:
1. **실전 표본 20건 미만이면 아무것도 바꾸지 않는다** (0건이면 백테스트 판정 그대로).
2. 방향이 95% 확신으로 갈라질 **때만** 바뀐다 — 애매하면 예전대로.
3. 백테스트가 `표본 부족`으로 판정한 전략은 사전을 30건 수준으로 약하게만 준다
   (없는 확신을 만들지 않음).
4. 모든 변경은 `▲ 자동승격/강등`으로 표시되고, 갱신 이력은 DB(`learn_history`)에 30건 보관.
5. 강등되면 해당 전략의 배지는 즉시 `제외`로 내려간다 — 사람 판단으로 되돌리지 않는다.
6. 판정은 **사이즈로도 반영**된다 — 사후 확정 통과는 종목 한도 ×1.25, 약한 근거(조건부·표본부족
   승격)는 리스크 ×0.9 / 한도 ×0.9 (§2-1). 총 60% 한도는 변하지 않는다.

> 발전형이라는 뜻이 "더 잘 맞는다"는 뜻은 아닙니다. 추정치의 **불확실성(구간)**이 줄어들 뿐,
> 실제 전략의 정확도가 자동으로 올라가지는 않습니다. 구간이 좁아졌을 때만 "더 정확히 안다"고
> 말할 수 있습니다.

## 6. 절대 금지

1. 손절 미이행 ("한 번 더 본다")
2. 자본의 1%를 넘는 수량 매수
3. 하락 추세 종목에서의 물타기
4. 뉴스·유튜브·팔로워 말로만 한 매매 (자문 배지 없이)
5. 연속 손실 후 사이즈 증액 (리벤지 트레이딩)

## 7. 기록

- 모든 매매는 `매매일지`에 **당일 기록** (진입가·손절가·수량·사유).
- 주문 시트는 `3. 매매 도구`에서 CSV로 내려받아 증권사 주문 화면에 입력.
- 주문 파일 규격은 `docs/orderspec.md`.

### 7-1. 매매일지를 서버에 올리는 법 (학습 자료로 쓰기)

일지는 기본적으로 **브라우저(이 기기)** 에 남고, 서버 학습 자료로 쓰려면 한 번 올려야 한다.

| 단계 | 할 일 |
|---|---|
| 1 | 폼에서 기록 → `일지 추가` (이 기기 localStorage) |
| 2 | **`서버에 올리기`** 클릭 → GitHub 새 파일(`data/journal/upload_YYYYMMDD_HHMMSS.csv`)이 내용까지 미리 채워져 열림 → **Commit new file** 클릭 |
| 3 | push를 받은 Actions(`journal-publish`)가 약 1분 안에 DB에 병합하고 `journal.json` 발행 |
| 4 | 새로고침 → 일지 상단 `서버 N건` 확인 · 발전형 게이트 옆 **실현 성적**으로 반영 |

- **중복 안심**: 같은 매매일+종목은 서버/이 기기 두 군데 있어도 자동 병합(`동기화됨` 표시).
  올린 뒤 이 기기 기록을 지우지 않아도 된다.
- 커밋이 어려우면 **`업로드 내용 복사`** → GitHub `data/journal/` 에 직접 붙여넣기.
- CSV 16열: `date,code,name,strategy,signal_date,side,entry,qty,stop,target,exit_date,exit_price,exit_reason,pnl,pnl_pct,memo`
  (`pnl`/`pnl_pct` 비어 있으면 진입·청산가로 자동 계산, `strategy`는 발전형 게이트 실현 성적 집계에만 사용)
- **실현 성적은 참고 표시다** — 신호 판정(익일 종가 적중률)과 실현 손익은 다른 사건이므로
  게이트의 베이지안 판정 수학에는 들어가지 않는다.
