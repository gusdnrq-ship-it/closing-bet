# 구글시트 연동 — 매매일지 자동 서버 반영

두 가지 방식이 있다. **둘 다 같은 `journal` 테이블로 병합**되고, 같은 매매일+종목은
자동 중복 제거되므로 함께 써도 된다.

| | 방식 A — 앱스(GAS) 커밋 | 방식 B — 웹 게시 CSV 가져오기 |
|---|---|---|
| 반영 시점 | **약 1분**(트리거) | 예약 실행까지 최대 12시간 · 수동 dispatch는 즉시 |
| 필요한 것 | GitHub PAT + 시트 스크립트 | **시트 '웹에 게시'만** (PAT·스크립트 없음) |
| 설정 난이도 | 중 | 매우 쉬움 |
| 권장 상황 | 매매 중 실시간 기록 | 하루 1~2회 정리 기록 |

둘 다 `data/journal/` 로 최종 도착해 같은 파이프라인을 탄다.

```
[방식 A] 구글시트 --1분 트리거--> GAS --> data/journal/sheet.csv (커밋)
[방식 B] 구글시트 --웹 게시 CSV--> Actions가 실행 시 직접 다운로드
                                        └--> push/실행 감지 --> journal-publish / daily-update
                                              └--> DB 병합 --> journal.json --> 사이트 표시
```

> 기존 방식(브라우저 일지 → `서버에 올리기` → `data/journal/upload_*.csv`)도 그대로
> 쓸 수 있다.

---

## 방식 B — PAT 없이 '웹에 게시'만 (설정 최소)

### B-1. 시트를 CSV로 공유

1. 시트에서 **파일 → 공유 → 웹에 게시** → **시트1(매매일지 탭)** → **CSV** 선택 → 게시 → 링크 복사.
2. 복사된 URL 은 `https://docs.google.com/spreadsheets/d/e/<ID>/pub?gid=<GID>&single=true&output=csv`
   형태다. 여기에 **그대로** 쓰면 된다.

> 다른 방법: `시트 액세스 권한을 '링크가 있는 모든 사용자'` 로 두고
> `https://docs.google.com/spreadsheets/d/<ID>/export?format=csv&gid=<GID>` 도 쓸 수 있다.
> `gid` 는 시트 하단 탭 우클릭 → 링크 복사에서 확인.

### B-2. 저장소 변수 등록 (한 번)

- GitHub 저장소 → **Settings → Secrets and variables → Actions → Variables → New repository variable**
  - Name: `SHEET_CSV_URL`, Value: B-1의 CSV URL
- 또는 CLI:
  ```bash
  gh variable set SHEET_CSV_URL --body "https://docs.google.com/spreadsheets/d/e/.../pub?...&output=csv" -R gusdnrq-ship-it/closing-bet
  ```

### B-3. 동작

- `daily-update`(평일 16:00·21:00 KST)와 `journal-publish`(push 시) 실행 때마다
  시트 CSV를 내려받아 DB에 병합한다. 실패해도 경고만 남기고 기존 데이터로 계속한다.
- **즉시 확인이 필요할 때**: Actions → 해당 워크플로 → **Run workflow** →
  `sheet_url` 입력란에 CSV URL 붙여넣기 → 몇십 초 뒤 `journal.json` 갱신.
- 헤더에 16열 규격이 하나라도 빠지면 **그 파일은 통째로 건너뛰고 경고**를 남긴다
  (한글 헤더로 붙여넣기한 경우 빈 행이 잔뜩 쌓이는 것을 막는다).

### B-4. 시트 1행 헤더 (방식 A와 동일)

- **템플릿 파일**: `docs/매매일지_템플릿.csv` — 시트 A1에 붙여넣거나 새 시트로 가져오기.
  (헤더 1행 + 예시 2행: 목표 청산 1건, 보유 중 1건)

```
date,code,name,strategy,signal_date,side,entry,qty,stop,target,exit_date,exit_price,exit_reason,pnl,pnl_pct,memo
```

열 설명·입력 규칙은 아래 **방식 A의 A-2** 표를 그대로 따른다.

## 방식 A — 앱스 스크립트 실시간 커밋 (약 1분)

### A-1. 준비: GitHub 개인 액세스 토큰(PAT)

1. GitHub → Settings → Developer settings → **Personal access tokens → Fine-grained tokens → Generate new token**
   - Repository access: **Only select repositories** → `gusdnrq-ship-it/closing-bet`
   - Repository permissions → **Contents: Read and write** (그 외 불필요)
   - 만료 기간은 1년(또는 정책에 맞게)
2. 발급된 토큰(`github_pat_...`)을 **어디에도 커밋하지 않는다.**
   - GAS 스크립트 속성에 저장한다(아래 A-3).
   - Actions에 넣을 필요는 없다(커밋은 GAS가 직접 한다).

### A-2. 시트 구성 · 헤더 규격

1. 새 시트 또는 기존 시트 탭 이름을 **`매매일지`** 로 둔다 (이름이 다르면 스크립트 `CFG.SHEET` 수정).
2. **1행에 아래 16개 영문 헤더**를 정확히 붙여넣는다 (순서·철자까지 동일해야 한다).

```
date,code,name,strategy,signal_date,side,entry,qty,stop,target,exit_date,exit_price,exit_reason,pnl,pnl_pct,memo
```

| 열 | 의미 | 예시 |
|---|---|---|
| `date` | 매매일 (진입일) | `2026-10-01` |
| `code` | 종목코드 (6자리, 앞자리 0 보존 → 셀 서식 **텍스트**) | `027830` |
| `name` | 종목명 | `호전산업` |
| `strategy` | 전략 키 | `bnf_oversold` / `breakout` / `ssanggul_bollinger` |
| `signal_date` | 신호 발생일 | `2026-10-01` |
| `side` | 방향 | `BUY` |
| `entry` / `qty` | 진입가 / 수량 | `746` / `100` |
| `stop` / `target` | 손절가 / 목표가 | `737` / |
| `exit_date` / `exit_price` / `exit_reason` | 청산일 / 청산가 / 사유 | `2026-10-01` / `780` / `목표` |
| `pnl` / `pnl_pct` | 손익(원) / 등락률(%) — **비워 두면 자동 계산** | `` / `` |
| `memo` | 메모 | `60일선 도달` |

3. 2행부터 기록. **`date`와 `code`가 빈 행은 자동으로 건너뛴다.**
4. 종목코드는 셀 서식을 텍스트로 두거나 `'027830` 형태로 입력한다(숫자 서식이면 앞자리 0이 사라진다).

### A-3. 앱스 스크립트 붙여넣기

1. 시트 → **확장 프로그램 → Apps Script**.
2. 아래 코드를 붙여넣고 저장.

```javascript
/* closing-bet 매매일지 → GitHub 자동 커밋 */
const CFG = {
  OWNER: "gusdnrq-ship-it",
  REPO: "closing-bet",
  PATH: "data/journal/sheet.csv",       // 저장소 내 업로드 경로
  SHEET: "매매일지",                     // 시트 탭 이름
  HEADER_ROW: 1,
  DATA_ROW: 2,
  COLS: 16,
  MSG: "chore: 구글시트 매매일지 동기화"
};
const HEADERS = ["date","code","name","strategy","signal_date","side",
  "entry","qty","stop","target","exit_date","exit_price","exit_reason",
  "pnl","pnl_pct","memo"];

function props_() { return PropertiesService.getScriptProperties(); }

/* 시트 → CSV → GitHub 커밋 (내용이 같으면 커밋 생략) */
function syncSheet() {
  const token = props_().getProperty("GH_TOKEN");
  if (!token) throw new Error("스크립트 속성 GH_TOKEN 을 먼저 저장하세요.");

  const sh = SpreadsheetApp.getActive().getSheetByName(CFG.SHEET);
  if (!sh) throw new Error("시트 탭 '" + CFG.SHEET + "' 가 없습니다.");

  const header = sh.getRange(CFG.HEADER_ROW, 1, 1, CFG.COLS)
    .getValues()[0].map((v) => String(v).trim());
  for (let i = 0; i < HEADERS.length; i++) {
    if (header[i] !== HEADERS[i]) {
      throw new Error("헤더 " + (i + 1) + "번이 '" + HEADERS[i]
        + "' 가 아닙니다 (현재: '" + header[i] + "').");
    }
  }

  const n = Math.max(sh.getLastRow() - CFG.HEADER_ROW, 0);
  if (n < 1) throw new Error("데이터 행이 없습니다.");
  const rows = sh.getRange(CFG.DATA_ROW, 1, n, CFG.COLS).getValues()
    .filter((r) => String(r[0]).trim() !== "" && String(r[1]).trim() !== "");

  const csv = [HEADERS.join(",")]
    .concat(rows.map((r) => r.map(csvSafe_).join(",")))
    .join("\r\n") + "\r\n";

  const cur = ghGet_(token);
  if (cur) {
    const old = Utilities.newBlob(
      Utilities.base64Decode(String(cur.content).replace(/\s+/g, ""))).getDataAsString();
    if (old === csv) return;                       // 내용 동일 → 커밋 생략
  }
  ghPut_(token, csv, cur ? cur.sha : null, CFG.MSG + " (" + rows.length + "건)");
}

/* 숫자/날짜/따옴표 처리 — 날짜 셀은 yyyy-MM-dd 로 강제(시트가 Date 로 해석하는 문제 방지) */
function csvSafe_(v) {
  if (v === null || v === undefined) return "";
  if (Object.prototype.toString.call(v) === "[object Date]") {
    return Utilities.formatDate(v, Session.getScriptTimeZone(), "yyyy-MM-dd");
  }
  const s = String(v);
  return /[",\r\n]/.test(s) ? '"' + s.replace(/"/g, '""') + '"' : s;
}

function ghHeaders_(token) {
  return {
    Authorization: "Bearer " + token,
    Accept: "application/vnd.github+json",
    "X-GitHub-Api-Version": "2022-11-28",
    "Content-Type": "application/json"
  };
}

function ghGet_(token) {
  const url = "https://api.github.com/repos/" + CFG.OWNER + "/" + CFG.REPO
    + "/contents/" + CFG.PATH + "?ref=main";
  const r = UrlFetchApp.fetch(url, { headers: ghHeaders_(token), muteHttpExceptions: true });
  if (r.getResponseCode() === 404) return null;
  if (r.getResponseCode() !== 200) throw new Error("GitHub 조회 실패: " + r.getContentText());
  return JSON.parse(r.getContentText());
}

function ghPut_(token, csv, sha, msg) {
  const url = "https://api.github.com/repos/" + CFG.OWNER + "/" + CFG.REPO
    + "/contents/" + CFG.PATH;
  const payload = {
    message: msg,
    content: Utilities.base64Encode(Utilities.newBlob(csv, "text/csv", "sheet.csv").getBytes()),
    branch: "main"
  };
  if (sha) payload.sha = sha;
  const r = UrlFetchApp.fetch(url, {
    method: "put", headers: ghHeaders_(token),
    payload: JSON.stringify(payload), muteHttpExceptions: true
  });
  if (r.getResponseCode() !== 201 && r.getResponseCode() !== 200) {
    throw new Error("GitHub 커밋 실패: " + r.getResponseCode() + " " + r.getContentText());
  }
  Logger.log("커밋 완료: " + msg);
}
```

3. **스크립트 속성에 토큰 저장**: 좌측 상단 **스크립트 속성 → 추가**
   - 이름: `GH_TOKEN`, 값: A-1에서 만든 PAT.

### A-4. 트리거 설정 (1분마다 자동 동기화)

1. 좌측 **트리거 → 트리거 추가**
2. 함수: **`syncSheet`**, 배포 대상: **이 스프레드시트**, 이벤트 소스: **시간 기반 주기 → 분 → 1분**.
3. (선택) `onEdit` 트리거를 붙여 즉시 동기화하려면 스크립트에 추가:
   ```javascript
   function onEdit(e) { try { syncSheet(); } catch (err) { Logger.log(err); } }
   ```
   단, 매 편집마다 커밋이 발생하므로 **1분 트리거만 쓰는 편이 안전**하다.

### A-5. 확인 절차 (첫 1회)

1. 시트 2행에 아무 데이터를 입력 → 최대 1분 대기.
2. GitHub 저장소 `actions` 탭 → **journal-publish** 실행이 뜨는지, **success** 인지 확인.
3. `data/journal/sheet.csv` 커밋이 떴는지 확인.
4. 사이트 → `static/api/journal.json` 의 `date`(발행 시각)와 `summary.total` 이 갱신됐는지 확인.
5. 사이트 새로고침 → 매매일지 상단 `서버 N건`, 발전형 게이트 옆 **실현 성적**.

## 오류 대응 (전 방식 공통)

| 증상 | 원인 / 해결 |
|---|---|
| `GH_TOKEN 을 먼저 저장하세요` | 스크립트 속성에 `GH_TOKEN` 없음 → A-3의 3번(스크립트 속성) |
| `GitHub 커밋 실패: 403` | PAT 권한에 Contents Read/write 없음 또는 저장소 미선택 → A-1 재발급 |
| `GitHub 커밋 실패: 409` | 동시 커밋 충돌 → 1분 후 재시도(트리거가 자동 재시도) |
| `헤더 N번이 ... 가 아닙니다` | 시트 1행 헤더 순서·철자 불일치 → A-2 헤더 복사 |
| 시트에 있는데 사이트에 안 보임 | (a) Actions `journal-publish` 실패 여부 확인, (b) 매매일+종목이 이미 서버에 있으면 **서버가 정본**이므로 시트 값과 다를 수 있음, (c) 사이트 새로고침 |
| 종목코드가 `27830` 으로 바뀜 | 셀 서식이 숫자 → 텍스트 서식 또는 `'027830` |

## 병합 규칙 (전 방식 공용)

- 키: **매매일 + 종목코드** (시트·업로드 CSV·브라우저 기록이 같으면 하나로 합침).
- 서버(`journal.json`) 값이 정본 → 화면에는 `동기화됨` 배지.
- `pnl`/`pnl_pct` 가 비어 있으면 진입가·청산가로 자동 계산.
- **실현 성적은 참고 표시**이며 발전형 게이트의 베이지안 판정 수학에는 들어가지 않는다.
