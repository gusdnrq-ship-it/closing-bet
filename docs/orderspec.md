# 주문 파일 규격 (orders.json / CSV)

대시보드 `3. 매매 도구 → 주문 시트`가 내려주는 주문 시트의 스펙입니다.
**자동 주문은 실행하지 않습니다** — 규격만 정의하고, 사람이 최종 확인해 증권사 화면에 입력합니다.

## 1. orders.json (사이트용)

경로: `static/api/orders.json` (export 시 자동 생성)

```json
{
  "date": "2026-09-28",
  "capital": 3000000,
  "max_total": 1800000,
  "used": 1198214,
  "used_pct": 39.9,
  "rules": { "entry": "...", "stop": "...", "target": "...", "risk_pct": 1.0,
             "max_pos_pct": 20.0, "max_total_pct": 60.0, "default_capital": 3000000 },
  "orders": [
    {
      "code": "003580",
      "name": "HLB글로벌",
      "strategy": "bnf_oversold",
      "side": "BUY",
      "qty": 100,
      "price_type": "LIMIT",
      "limit_price": 7190,
      "entry": 7190,
      "stop": 5650,
      "target": 6720,
      "invested": 719000,
      "invested_pct": 24.0,
      "max_loss": 154000,
      "conf_mult": 1.25,
      "conf_note": "사후 확정 통과 (사후 54.2%, 95% 47.7~60.6% > 기준선 45.99%) — 한도 25%",
      "risk_budget": 30000,
      "max_pos": 750000,
      "signal_date": "2026-09-28",
      "note": "검증 58.3% · 기준선 45.99% 통과 (breakout은 현재 전량 제외)"
    }
  ],
  "caveats": ["본 자문은 참고자료이며 매매 추천이 아니다...", "..."]
}
```

### 필드 설명

| 필드 | 뜻 |
|---|---|
| `side` | `BUY` (공매도 `SELL`은 지원하지 않음) |
| `qty` | 수량. `min(종목별 1회리스크한도 ÷ (진입가−손절가), 종목별 한도 ÷ 진입가, 남은 총한도 ÷ 진입가)` — ★ 선정→순위 순으로 **순차 배분**, 총 60%에 닿으면 이후 종목은 `qty=0` |
| `conf_mult` | 게이트 신뢰도 배율 (`1.25` 사후 확정 / `1.0` 기본 / `0.9` 조건부·표본부족 승격) |
| `conf_note` | 배율의 근거 한 줄 (사후 적중률·95% 구간 등) |
| `risk_budget` | 이 종목에 배정된 1회 리스크 한도 = `자본 × 1% × min(conf_mult, 1)` — **1%를 넘지 않음** |
| `max_pos` | 이 종목의 투자금 한도 = `자본 × 20% × conf_mult` (1.25 → 25%, 0.9 → 18%) |
| `qty = 0` | 실행하지 않음. `note`에 사유 (`총 매수 한도(60%) 도달 — 대기` / `신뢰도 ×0.9 적용 한도(...)로는 매수 불가` / `1회 리스크·종목 한도로는 매수 불가` / `손절선이 진입가 이상 — 매수 불가`) |
| `max_total` / `used` / `used_pct` | 총 매수 한도(자본×60%) — **신뢰도 배율과 무관**, 실제 배분액, 사용률 |
| `price_type` | `LIMIT` (지정가). 시가 ±1% 안에서 체결 시도 |
| `limit_price` | 기준 가격 (= 신호일 종가). 실주문 시가가 이 ±1% 밖이면 체결 포기 |
| `stop` | 신호 이전 60거래일 최저가 — **하회 시 즉시 시장가 매도** |
| `target` | 60일 이동평균 — 도달 시 매도 |
| `max_loss` | `stop`까지 가면 손실액 (수량 기준). `risk_budget` 이하가 되어야 정상 |

## 2. CSV 내보내기

`매매 도구 → 주문 시트 → CSV 다운로드`가 만드는 열:

```
date,code,name,strategy,side,qty,price_type,limit_price,stop,target,max_loss,conf_mult,risk_budget,max_pos,signal_date,note
```

- 인코딩: **UTF-8 BOM** (Excel 한글 깨짐 방지)
- 엑셀/구글시트에서 열어 수정 후 증권사 HTS의 주문 화면에 수동 입력

## 3. 자동 주문 연동 (별도 — 미포함)

증권사 자동매매는 아래 사유로 **이 저장소에서 제공하지 않습니다**:

1. 키움 OpenAPI·나무 등은 개인별 API 키/HTS 우회설치·실전 계좌 인증이 필요
2. 자동 주문은 오류 시 자본 손실로 직결 — 사람이 확인하는 단계를 생략할 수 없음
3. 증권사 약관상 자동매매 프로그램의 책임·신고 요건이 있음

필요하다면 위 규격(`orders.json` / CSV)을 입력받는 **본인 소유 프로그램**을 별도로 만들고,
아래 순서를 지켜야 합니다:

1. 주문 시트 생성(이 저장소) → 2. 사람 검수(수량·가격·한도) → 3. 본인 프로그램 전달 →
4. 소액 모의/최소 수량으로 1주 시험 → 5. 실전

## 4. 면책

주문 파일은 **참고용 제안**이며 매수 추천이 아닙니다. 체결 여부·슬리피지·수수료·
상하한가는 반영되지 않습니다. 최종 책임은 주문을 입력하는 사람에게 있습니다.
